# T013：RV64 F/D 2.2 与压缩 D 访存

状态：verified（2026-10-12），依赖 T012 verified（390bba5）。持续 Linux/Spike 总目标。

固定官方 Ratified-IMAFDQC 的 F/D 2.2（f.tex blob
768034786ab8342a9ca223c5e374b269e861e673；d.tex
8119f478dfac79bd0d064233156c317ad1e7390f）。F depends Zicsr，D depends F。
实现 32 个 FPR、FCSR/FFLAGS/FRM 别名与 FS 权限/dirty、FLEN32/64、D 下单精度
NaN boxing。FPR f0 可写；GPR x0 丢弃。浮点异常只累积 flags，不 trap。
支持五个舍入模式、动态 frm，保留 rm/frm 选择 illegal；NaN canonical、sNaN、
subnormal/tininess-after-rounding、signed zero、饱和转换与 RV64 W/WU 符号扩展。

实现 F/D 的 load/store、add/sub/mul/div/sqrt、四类 FMA、min/max、sign injection、
compare/class、int/float 与 S/D conversion、raw moves，C.FLD/FSD/FLDSP/FSDSP。
地址与 fault 经已验证集中路径，FS off/非法 encoding 不改目的寄存器或数据。
允许 FS 保守 dirty，采用与固定 Spike 相同的观测规则：FPR 写与 FCSR 写 dirty；
纯读/GPR 精确结果/无异常的 compare/store 不 dirty，flags 变化 dirty。

核心保持 C。使用固定 Spike 归档内的 SoftFloat C 算术子集，保留许可证、来源
与每文件哈希；RVISS 自己实现编码/权限/boxing/状态/访存，独立参考仍执行完整
Spike 指令语义。算术库共享有共同错误风险，必须另有规范常量与 IEEE 边界
unit，而非仅对拍或以同一库调用当 test oracle。未验证前不置 misa F/D。

工具输入独立 FPR/FP CSR，比较全 FPR、FCSR、已有事件/CSR/RAM/退休；F-only
只比较其体系结构 FLEN32 位，D 为64。明确初始化共同 FP 状态，不运行中同步。
验收包含正常/边界/舍入/NaN/boxing/别名/FS off、F-only/D关闭、关闭全部 FP，
浮点分页/PMP faults、压缩 D 编码完整差分、真实加载/store序列、UBSan、重放
与 FP 故意差异注入。三配置回归；保持整数/特权/MMU完整比较。

完成继续 T014 virt UART/PLIC/CLINT/finisher，再固定 Linux 与重复 workload。


首构建失败：本地 nan 函数名与 C builtin 冲突，已改名，未关闭严格告警；
完整输出 t013_first_build_failure.json。首 unit 578 checks 有 1 个错误预期：
依据 [IEEE754-2008 §7.5](https://andrewt0301.github.io/hse-acos-course/part1ca/07_FP/ieee-754-2008.pdf)，
tininess-after-rounding 用完整精度、无限 exponent 的舍入结果，最终位模式 normal
仍可能 UF。精确推导、旧失败与修改依据见 t013_first_unit_failure.json；保留该
用例并增加真正区分 before/after 的 paired case，模拟器/算术库未改变。

最终验证：GC 17141 cases / 83079 events（含 8192 个压缩 FP 编码）；F-only
7558 / 47058；minimal 2203 / 5255；GC UBSan 8949 / 74887。全部独立进程
重放通过，GC/F-only/UBSan 四种故意差异（GPR/store/trap/FPR）均捕获；
minimal 三种捕获。所有 DUT/ref 二进制哈希与最终报告一致。
GC/F-only/minimal 各 15 unit、3 smoke、14 CLI checks；FP 分别648/563/7 checks。
UBSan FP 648 checks 无诊断。实际命令、完整输入身份与结果见
`docs/validation/t013_checks.json` 和 `t013_{gc,f,minimal,ubsan}_spike.json`。

首参考初始化失败由 FS=0 时公开 FP CSR 写权限引起，初始化临时 enable/restore
FS 后正常；F-only 首差异来自 Spike 私有128位 FPR 的初值 boxing 表示，
仅规范化 FLEN32 初值的参考表示，架构低32位输入与观测不变。旧 C unit
断言 F/D 不存在随能力扩展已更新为按配置检查；保留旧失败记录。没有改变
执行时期参考状态、关闭检查或扩大 skip。

固定 Spike 全1639文件及 vendored SoftFloat 全71来源文件 byte-identical。
数字算术共享同源库的共同错误风险仍存在，独立 IEEE 常量边界 unit 补充覆盖。
